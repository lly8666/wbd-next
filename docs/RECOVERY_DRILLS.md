# 治理演练与验证范围

自动演练只验证治理算法与反例处理，不是实际“全新聊天理解项目”的证明。

治理测试覆盖：正常 H、S 后中断、源码修改后撤回、错误 checkpoint、过多未核对提交、写入范围冲突、旧 epoch、请求重复、错 SOURCE/config、缺失证据、上下文膨胀、删除仍被引用的历史文件与未分配角色等。是否实际通过以精确 SOURCE 的 Actions 记录为准。

检查器能发现缺失的当前引用；对不再引用的旧历史如何归档，仍需 Git diff 审查，不能宣称自动证明所有历史语义都保留。

另用临时 Git 仓库产生真实 S/H/change-then-revert 提交，验证逐提交而非净 diff 判断。

真实 fresh-chat 演练目前 `NOT_RUN`。以后只给接手者 repo + role 固定提示词，不泄露当前 HEAD、run 或下一步，验收其能否从 GitHub 重建：项目目的、当前任务、writer 身份、未确认差异、Actions 结果范围、一个正确下一动作。不得靠创建自问自答报告宣称这项通过。

故障恢复演练只用测试夹具，不故意破坏生产 main、取消别人的 Actions 或修改用户物理机器。
