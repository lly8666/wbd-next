**接班**　假定上轮可中断于任何一步。刷新远端 main，只读[启动页](../../START_HERE.md)、上述热入口与当前计划。按 cursor 的 checkpoint 查增量，核对活动分支/PR、实际 HEAD、SOURCE、未完 intent、Actions run/attempt。已发先收结果，已合先核 main；查无分支按登记基线创建，只有 WIP 就续同一分支。未推本地内容视为未知。发现未登记结果，补实际事实后继续；发生竞争先核远端最新写者和差异。
