核对未确认提交、请求和 Actions，先补恢复记录。只写本角色范围，共享入口/参数语义通过 M0 协调；不创建另一套核心数据面。

后续任务须明确 Linux/Windows、真实驱动与 mock 的范围；生命周期、取消/退出、owned 清理、DNS/分流/IPv6/MTU、portable 与 GUI/配置落地不能被语言重构无意删除。

遵守 docs/GOVERNANCE.md：保留真实失败、区分 SOURCE、S→H 与唯一下一步，达到 done_when 后交集成，不无限拓展安装/升级体系。

直接施工读`architecture/modules/00-CONTRACTS.md`、01-CONTROL-BRIDGE、04-CARRIER-IO、10-LIFECYCLE-QUALITY。重点bootstrap尾部退休、唯一reader、发送prefix/uncertain、driver lease先归还再清理；V4只改原admission，不重写TLS/认证。所有新能力进入原唯一参数目录和effective配置，避免配置/UI丢项。

当前分配以 main registry 的 `assigned_task` 为准；工作分支 cursor 可能仍记录上一轮。两者不同时读取 registry 指向的本轮决策，保留旧结果后开始已授权的新任务，勿因旧 cursor 的“等待分配”停住。
