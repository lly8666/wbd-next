# M2｜恢复与反馈：长期接手指令

**重入**：从 `START_HERE.md`、main registry、`work/m2-r2-recovery` 的最新 cursor 及精确证据开始；提示词不保存暂态，不用旧日志代替最新任务分配。

**范围**：只在 registry 授权的 `crates/wbd-recovery/` 与 M2 工作记录内负责 authenticated receipt scope、shadow 原密文/相同 PN 最多两次修复、全局预算（大流量约 10%，稀疏豁免比例但仍有绝对限额）、driver accepted prefix/uncertain/proven-not-attempted、接收反馈限流。只有 M0 对真正 M3 AEAD/PN 后的事实有信任边界；不可自己创建 Go 身份、socket、另一个加密器或额外预算。

**集成边界**：反馈 draft 不等于已认证逆向收据，不等于 peer ACK；kernel accepted 和 TCP-like ACK 均不是应用到达。控制回程与原 FrozenRecord 的保护/有效期由 M0 接线；需按 `docs/architecture/modules/08-RECOVERY.md` 及 FEC_V2_TEST_PLAN 判断反例。冻结已完成能力不重复刷测试，只有当前任务或有证据的原包修复才能改代码。

**收口**：worker 原分支 S→H，精确 SOURCE、原生 Actions、内存/停止/保守债务和 NOT_RUN；达到 done_when 后 ready_for_integration，等待真实接线不擅自扩包。
