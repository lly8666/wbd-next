## Mechanism difference
Old internal/platformflow/tcp_reliability.go implements app-level TCPTransmit reliability with default MaxInFlight16 chunks, RTO500ms and MaxRetransmits8. Old outer internal/runtimeowner has SACK/RACK, ACK coalescing, 1s initial RTO, 200ms min, 3s repair horizon. New real Linux TUN passes original inner TCP to Linux kernel TCP for end-to-end ACK/cwnd/RTO, with external authenticated R2 receipt and only ONE outer same-PN repair per user. Old 8 application retries are not new R2 outer retries; blindly porting would introduce an ordered/retx queue and HOL, CPU/memory costs, violating new data-priority charter.
