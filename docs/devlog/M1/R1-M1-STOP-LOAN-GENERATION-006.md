## Scope and nonclaims

`runtime/generation.rs` is an opt-in `ScopedOwner` facade. It uses the existing `TxOwner`, `RxOwner`, previous 32-capped caller-preallocated ready batch APIs, `FrozenRecord` metadata and `Arena` return accounting without touching old callers, shared ABI, driver, Cargo, or root CI. `ScopeToken` uses an `Arc<Tag>` allocated ONLY at create/rotation; both pointer identity and monotonically increased nonwrapping serial are checked. A restarted owner with coincidentally identical numeric owner/serial/lane values does not accept prior token callbacks (ABA). Frozen TX record metadata must match the full caller-supplied lane key (tunnel/lane full generations) before any offer. No authentication is invented: the metadata is assumed caller-established; a forged current token or metadata is outside this proof.

Rotation rejects reused lane identities, invalid next generation and serial exhaustion without stopping the original owner. A valid rotation stops both old TX/RX queues, cancels only unsubmitted handles, replaces with caller-precreated bounded owner queues, allocates a new scope token and shared batch ledger on CONTROL path, and returns a `RetiredScope`. Old queued ciphertext never migrates into the new generation; incoming callbacks with stale Arc identity return original immutable record/unique buffer. New fresh can dispatch immediately without waiting on old in-flight loans, if the shared arena has independent free capacity. Stop requests after rotation cannot touch a fresh generation via old token.

`LoanBatch<T>` is a strict ownership container of an already-allocated Vec. The runtime dispatches up to 32 ready handles into the passed empty Vec, without allocation, ciphertext copy or record clone. It lends only immutable slices. It cannot extract raw Vec while the ledger counts its lifetime, except `recycle()` which **first drops all handles**, decrements the batch count, then gives caller original empty Vec for reuse. `RetiredScope::borrowed` reports exact scoped outstanding TX/RX batch handles. It NEVER claims `Arena` all-loans quiescence: extra FrozenRecord clones may remain after batches drop and are accounted exclusively by arena loan/return generation, so callers must also inspect `Arena::report().loaned` when the arena has been fully stopped and has no newer scope work. This is a model-layer stop/borrow fence, not driver asynchronous completion.
