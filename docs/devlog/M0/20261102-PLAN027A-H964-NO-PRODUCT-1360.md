# PLAN027A H964｜正式Go产品内彻底撤走DefaultMSS=1360

H959–H963已用Rust冷预算安装现行FakeTCP SYN/SYNACK MSS，并冻结每个association。但从源文件逐行审查发现 `packet.go` 还导出了旧`DefaultMSS=1360`常量，虽正式V4已不引用，也不允许在用户明确禁用兼容逻辑时继续保留。

H964从**生产Go文件**删掉该常量，仅将上游原Go历史单测矢量`DefaultMSS=1360`放进原已source-locked`public_v4_mss_test.go`。这是编译期测试文件，不进入任何客户端/服务端程序；现行生产唯一出口`PublicV4AdvertisedMSS`仍需Rust预算真实初始化，否则直接拒绝运行，不会向1360回退。真实必要的1400→1360是显式1400预算结果而非默认。重钉两个正式原Go装配manifest准确Git blob、更新M4当前授权source hash。没有引入legacy/modern开关。

当前H964新SOURCE仍需Windows/Linux编译+真实握手MSS/协商record与Wintun/TUN验证，不将H963或H957任何旧source native PASS冒充。H958 DF失败继续挂账。
