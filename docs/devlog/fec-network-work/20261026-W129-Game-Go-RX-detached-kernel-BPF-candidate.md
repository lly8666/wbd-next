## Problem and proven receiver ownership boundary

The pinned original Go source is `lly8666/wobuzhidao@a7a82db31fe736ffedee330795a3234d358f1984`, `internal/faketcp/raw_linux.go`. `RawIPv4Endpoint.ReadSegment` receives on an **AF_PACKET** `recvFD`, parses the packet, allocates and copies the complete IPv4 packet in `rawOwnedParsedIPv4TCP`. `WriteSegment` uses a **separate AF_INET `sendFD`**. Original `r0/go_overlay/internal/v4productcli/game_linux.go` checked `ClientAssociationDetached` / `TransitionDetached` only **after** `ReadSegment`, causing wasted reads/parse/copies on all steady Game DATA even while Rust was delivering them. W126 Game4/20 sampled roughly 11 CPU-s of non-Rust RX/TX threads on one side, **not** proof that all of it is recoverable.

`V4LinuxGameProduct.commitGroupedOwnerLocked` calls `startNativeM4` then checks `originalCryptoState` ready before returning success. Both `ConnectClientGame` and `AcceptServerGame` return only after this authenticated Rust M4 receiver setup. Rust has separately opened per-lane `ScopedRawIpv4Rx::open_exact_tuple` sockets; its receiving does not depend on the Go AF_PACKET FD staying in the DATA path.

## P0 candidate changes (one isolated optimization)

- `r0/go_overlay/internal/faketcp/raw_game_detach_linux.go`: atomically replace the **existing AF_PACKET receive-port cBPF** with a strict *peer IP + peer port + local port* gate after handoff. Filter records with actual TCP payload to Go **only for the detached peer**; unchanged Go port/IP filter still rejects unrelated destination ports. Preserve pure ACK, SYN including SYN+payload, FIN/RST, and other peers' handshakes on the same listener. Handle IPv4 IHL and TCP data offset, not TCP PSH heuristics or fixed 20B header assumptions. Never close the Go send FD or entire raw endpoint. Fail closed if the original socket was not kernel-port-filtered.
- `r0/go_overlay/internal/v4productcli/game_linux.go`: on both client and server verify all lane association transitions, arm scoped receive filters **only after** the authenticated `ConnectClientGame/AcceptServerGame` returned and Rust is ready, then mark connected. If any filter or scope check fails, stop/close the native group; remaining Go raw sockets are closed by the existing deferred owner. Atomic stop-time `go_data_full_copies` counts only Go-returned DATA after a committed handoff, **not** total packets rejected by the kernel.
- `r0/go_overlay/internal/faketcp/raw_game_detach_linux_test.go`: classic BPF offline execution tests for detached DATA, IP+TCP options, ACK/FIN/RST, same tuple fresh SYN+payload, other peer/port and unrelated destination. No extra runtime per-packet instrumentation.
- `tools/arm64_public_go_rust_bundle.sh`: explicit overlay copies plus Go cBPF test. Required because this build script copies Go overlays by allowlisted names; merely adding the file to `r0/go_overlay` would **not** change the real binary.
