### Frozen M0 interface and owner lifetime

`ipv4_tcp::build_scatter_header<H:FrozenRecordHandle>(tuple,presentation,record,authenticated_options,mtu,header) -> Result<usize,PacketError>` generates a preallocated IPv4/TCP header + checksums (original frozen payload is **not copied**). `ScopedRawIpv4Tx::send_kernel_multimsg<H:FrozenRecordHandle>(&self,generation,records,tuple,presentations)->KernelSendReport` prevalidates <=32 first frames, uses one BorrowFence STOP guard and original owner mutex, then one kernel `sendmmsg(MSG_DONTWAIT)` with exact `[header, frozen ciphertext]` borrowed iovecs per datagram. A 33rd frame is not inspected. `ScopedRawIpv4Rx::receive_kernel_multimsg(&self,generation,buffers,tuple,persona)->Result<RawReadyBatch,RawTxError>` wraps a single `recvmmsg(MSG_DONTWAIT|MSG_TRUNC)` into the caller's unique slot arrays under existing outer+inner BorrowFence ready guards and owner mutex, validates tuple/checksum/MTU and moves valid **unauthenticated** ciphertext only within the same slot before returning. No Go/AEAD/PN authority is manufactured. At Stop, active synchronous syscall/parsing loans must drain; original delayed frozen record/PN loan is held by original owner until explicit old-generation completion, fresh generation independent.

Output semantics: `KernelSendReport {outcome.accepted_prefix, outcome.uncertain_index, outcome.error, signal}` is copied-to-kernel only, **not ACK**. Linux positive partial `sendmmsg` loses later errno: retain `PartialErrnoUnavailable` and untouched tail; actual errno90 EMSGSIZE poisons route cache, `EAGAIN` backpressure, `EINTR` and short/unknown completion uncertain, `ENODEV`/route failures invalidation, local PMTU preflight is `PacketExceedsBudget` without fake kernel errno. `RawReadyBatch` exposes `Unauthenticated{cipher_len,seq32}`, `Truncated`, `Rejected`, `Unused`; no ciphertext authenticated on receipt. `ScopedTunSink::read_ready_batch` and `write_ready_batch` retain <=32 sequential nonblocking read/write (TUN cannot be called a real `recvmmsg/sendmmsg` single-syscall multi-send).
