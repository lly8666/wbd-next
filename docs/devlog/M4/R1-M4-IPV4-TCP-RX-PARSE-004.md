## Design and proof
`parse_data_packet(&[u8], TrustedRx)` takes a **single caller-delimited whole IPv4/TCP packet**, trusted tuple/persona/options/MTU, and validates strictly: exact 20B IPv4 (v4/IHL5/TOS0/DF-only, proto6), exact IP total length and actual MTU, src/dst IPv4 and ports, TTL as persona, TCP DATA only ACK|PSH, offset/reserved/urgent pointer, options only if matching authenticated snapshot, and independent Internet checksums for IPv4 and TCP including odd-length ciphertext. Rejects truncation/trailing bytes, IP fragmentation, spoofed tuple and checksum, unsupported/SYN/SACK/implicit timestamp options. No new alloc/lock/unsafe; `UnauthenticatedData<'a>` only borrows ciphertext; checksum never means AEAD authentication, real receipt, replay acceptance or business delivery. Only M3/M0 can authenticate/decrypt and install delivery/ack.

`extend_seq32(trusted_seq64_anchor, wire32)` returns the nearest candidate at strictly less than 2^31 unsigned modulus distance, rejects exact half-space ambiguity, out-of-range u64 and never updates the trusted anchor itself; reference must originate in already trusted caller state. Testing uses actual bytes from existing M4 IPv4/TCP writer plus independently pinned legacy Go packet `lly8666/wobuzhidao@a7a82db31fe736ffedee330795a3234d358f1984` `internal/faketcp/packet.go` blob `6ac1f9b3d7208278d31078be8d61e2f3a6dbbd3b`. The old Go binary/oracle program was not run here.

Ten new native Rust `r1_rx_` tests cover odd/even golden bytes, exact MTU and minus-one, total/offset/truncation/fragment/flags, wrong source/ports/checksums, negotiated timestamp isolation, seq32 wrap/half-space, unrelated packet no HOL, and explicit unauthenticated ciphertext safety. Existing 21 M4 R1 tests remain passing.
