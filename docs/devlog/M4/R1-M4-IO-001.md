## S — isolated implementation (test results pending)

`crates/wbd-platform/src/r1.rs` is the isolated R1 API; it consumes M0 `FrozenRecordHandle` and `driver_read(&handle)` without mutation, reallocating, re-encrypting, or cloning the payload for synchronous sends. `submit_ready` tries at most 32 ready records, does not sleep/wait, returns `TxBatchOutcome` with definite copied prefix, one conservative uncertain frame on short/ambiguous I/O, and untouched suffix. WouldBlock means no attempt on the current record. `BatchResult` validates the outcome and classifies each index lazily with zero batch `Vec` allocation; `ReadyTxLedger` commits bounded counters transactionally. This does not equate syscall acceptance with authenticated receipt.

The new R1 `BorrowFence` uses a single atomic stop/count word: acquire races stop via CAS, no mutex on acquire or ordinary completion. Asynchronous `KernelLoan<FrozenHandle>` **moves** ownership of the immutable handle into the driver completion token; it is dropped **only** after verified completion/cancel. `wait_drained_until(Instant)` is bounded and returns `Pending{outstanding}` if timeout expires, explicitly **forbidding** driver/device close/free/unmap/EndSession. The token, backing ciphertext and fence remain retained for late completion. Synchronous copied syscall path never creates a loan. The old unbounded R0 fixture wait is test-only and not part of the R1 production interface.

`ConnectedUdpTx` is nonblocking, OS-native connected UDP for a single immutable datagram smoke round trip; it is **not** AF_PACKET/sendmmsg, Npcap, Wintun, TCP persona, nor a full encrypted normal record. The carrier adapter uses a trait so M0 may integrate an appropriately qualified native raw backend without changing M1/M3/ABI/root files. Any common-ABI/root changes must be requested from M0; none made here. `r1/go-bridge/`, GUI, installation and the old Go repository untouched. Go V4 remains disabled.
