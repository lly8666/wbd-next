## Owned implementation and FFI audit
Files `crates/wbd-platform/src/linux_batch.rs`, local module registration in `src/lib.rs`, and atomic R1 `BorrowFence` extension in `src/r1.rs`. Implements a **real** `sendmmsg` libc syscall with `MSG_DONTWAIT`, at most 32 prevalidated frozen record slices, one stack `iovec + mmsghdr` per datagram; no `Vec`, heap, mutex or per-frame Arc clone in the syscall path. Respects `FrozenRecordHandle::bytes()` strictly read-only; only borrowing pointer cast matches required POSIX `iovec`, kernel copies datagrams synchronously. One per-batch `ReadyBatchGuard` CAS registers with stop bit atomically; no new send after stop; stop cannot report drain until in-flight syscall releases batch guard. Last release only locks Condvar if shutdown bit already set. It does NOT substitute a fake async kernel loan and does not release any OS device.

ABI island exclusively compiled on Linux **x86_64 GNU** with `#[allow(unsafe_code)] pub mod linux_batch`; crate root changed `forbid`→`deny` because a real libc call necessarily crosses unsafe FFI, and all other code retains the deny. `repr(C)` `iovec,msghdr,mmsghdr` layout is checked in actual native test: sizeof 16/56/64, offsets 16/24/40/48/56. No libc external crate / Cargo.lock / shared tools changed; platforms outside that cfg have no exposed native batch module, so no cross-platform qualification is asserted.

Return mapping: a fully copied positive syscall prefix is **not** a peer ACK; short accepted batch retains definite unsent suffix and loses errno per Linux manpage, reported as `IoFailed` until owner's retry strategy; a stopped/overflow batch is NotSent; `EAGAIN` definite NotSent; ambiguous EINTR/unknown error one `IoUncertain`; impossible short datagram completion is conservatively classified as ambiguous without re-seal/splitting. At cap32, remaining ready suffix is NotSent. Upstream PN/seq and ciphertext immutable.
