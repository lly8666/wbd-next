Pure Rust `global_sparse.rs` adds a single-owner, explicitly bounded process Repair allocator with separate per-(TunnelKey,direction) local RepairBudget and one aggregate process cap. A finite GrantLease reserves **real** global bytes before dispatch; the existing per-direction 1s max(F/10,32768) still gates reserve, so 32KiB sparse allowances are NOT issued once per idle client. Distinct TunnelKey generations and both wire directions share the absolute cap; max direction count, pending count/bytes, grant size/lifetime, epoch cap and original-local MTU/pacer all explicitly limited. No global mutex/atomic, socket, PN allocator, new ciphertext, lockfile or engine/platform modifications.

Inject fake MonoNs into all APIs. Only confirmed first sends update F and are allowed even when no grant/repair cap. Grants expire at min(assigned TTL, next 1s epoch); unused held credits are revoked, while submitted/uncertain repair bytes retain their debit. A definitely NotSent callback refunds only the original accounting epoch (and same-epoch still-active original grant); an old-epoch refund never mints new free quota. Stale grant / duplicate completion / timeout / client departure all fail closed. Lost completion/departure counts as conservative uncertain debit; current-epoch missing completions are not double-debited against the same current epoch hard cap. Client retirement removes both directions, unused grants and bounded pending metadata, but cannot relabel an in-flight send as not sent. Unique monotonic grant/reservation ids do not recycle.

New `r2_global_*` fake-clock tests cover 2+ tunnels, both directions, zero-F sparse, aggregate limit, grant expiry/revoke, old epoch refund, double completion, two epochs, bound/exhaustion, uncertain timeout, client exit and fresh independent delivery. Test-only FakeFrozen uses Arc<[u8]> to ensure candidates originate as original immutable ciphertext; no actual product crypto/network is run.

Limitations passed to M0: process actor/routing verification, actual M1/M4 syscalls and completion provenance, actual shared driver byte accounting, production global process actor performance/fairness and live Go V4 admission remain separate NOT_RUN.
